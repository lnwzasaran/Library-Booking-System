**ประเภทโปรเจกต์:** ระบบจองห้องอ่านหนังสือ (Room Booking System)  
**กลุ่มผู้ใช้งานหลัก:** นักศึกษาวิทยาการคอมพิวเตอร์ ภาคพิเศษ จำนวนประมาณ 80 คน  
**ภาษาในการพัฒนา:** Java

## 1. ที่มาและความสำคัญ

โปรเจกต์นี้จัดทำขึ้นเพื่อช่วยให้นักศึกษาสามารถค้นหาห้องอ่านหนังสือ ตรวจสอบรายละเอียดห้อง และจองช่วงเวลาที่ต้องการใช้งานได้อย่างสะดวก รวมถึงช่วยให้ผู้ดูแลระบบจัดการข้อมูลห้องและตรวจสอบรายการจองได้จากระบบเดียว

## 2. วัตถุประสงค์

1. เพื่อให้ผู้ใช้สมัครสมาชิกและเข้าสู่ระบบได้
2. เพื่อให้ผู้ใช้ดูรายการห้องและรายละเอียดของแต่ละห้องได้
3. เพื่อให้ผู้ใช้จองห้องตามวันที่และช่วงเวลาที่ต้องการได้
4. เพื่อให้ผู้ใช้ตรวจสอบและยกเลิกรายการจองของตนเองได้ตามเงื่อนไขของระบบ
5. เพื่อให้ผู้ดูแลระบบจัดการข้อมูลห้องและตรวจสอบรายการจองทั้งหมดได้

## 3. ฟังก์ชันหลักของระบบ

### สำหรับนักศึกษา (Student)

- **Sign Up:** สมัครสมาชิกใหม่
- **Login:** เข้าสู่ระบบด้วยบัญชีผู้ใช้
- **Dashboard:** ดูข้อมูลและเมนูหลักของระบบ
- **Room List:** ดูรายการห้อง รายละเอียด และความจุของห้อง
- **Booking:** เลือกห้อง วันที่ และเวลาเพื่อทำรายการจอง
- **Booking Success:** แสดงผลเมื่อทำรายการจองสำเร็จ
- **My Bookings:** ดูรายการจองของตนเองและสถานะการจอง
- **Profile:** ดูหรือแก้ไขข้อมูลส่วนตัวตามที่ระบบอนุญาต
- **Logout:** ออกจากระบบ

### สำหรับผู้ดูแลระบบ (Admin)

- **Admin Dashboard:** ดูภาพรวมการใช้งานระบบ
- **Manage Students:** จัดการข้อมูลนักศึกษา
- **Manage Rooms:** เพิ่ม แก้ไข หรือปิดใช้งานข้อมูลห้อง
- **All Bookings:** ดูและตรวจสอบรายการจองทั้งหมด

## 4. เทคโนโลยีที่ใช้

- **Programming Language:** Java
- **Object-Oriented Programming (OOP):** ใช้แนวคิดคลาส วัตถุ Encapsulation และความสัมพันธ์ระหว่างคลาส
- **UI Design:** Figma
- **Database:** ระบุชื่อฐานข้อมูลที่กลุ่มใช้งานจริงก่อนส่งงาน
- **Development Tools:** ระบุ IDE และเครื่องมือที่กลุ่มใช้งานจริงก่อนส่งงาน

> หมายเหตุ: ควรแก้ไขรายการเทคโนโลยีให้ตรงกับเครื่องมือที่ใช้พัฒนาจริง ไม่ควรระบุเทคโนโลยีที่ยังไม่ได้ใช้งาน
